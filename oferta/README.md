# oferta/ — strona sprzedażowa

To statyczna strona oferty rolek reklamowych dla lokalnych firm z Katowic (`index.html`, `cennik.html`, strony prawne, wspólny `style.css`, czcionki w `fonts/`), serwowana przez GitHub Pages pod https://siles69.github.io/kinowy-autopilot-feed/oferta/. Filmy demo i postery są w `../demo/`, a strony przebudowuje się skryptem `../qa/build_pages.py` (treści prawne są w `../qa/old/`). Materiały operacyjne — lista firm, szablony wiadomości, ogłoszenia, dzienne listy i automatyzacja — są w prywatnym repozytorium `siles69/kinowy-sprzedaz`, nie tutaj.
